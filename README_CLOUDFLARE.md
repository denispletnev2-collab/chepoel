# Развёртывание NutriScan AI v3.0 на Cloudflare Pages (и установка через Chrome)

## 1. Структура проекта (Чистая модульная архитектура)
- `index.html` — семантическая разметка приложения
- `manifest.json` — конфигурация установки PWA на телефон и ПК
- `sw.js` — Service Worker для офлайн-работы и кэширования
- `_headers` — настройки кэширования и заголовков безопасности специально для Cloudflare Pages
- `css/tokens.css`, `css/layout.css`, `css/components.css` — модульные таблицы стилей и анимации рамок профиля
- `js/store.js`, `js/ai.js`, `js/profile.js`, `js/ui.js`, `js/app.js` — модульная логика приложения
- `assets/data/ru-products.json` — вынесенная база из 615 российских продуктов и блюд
- `assets/icons/` — иконки приложения (`192x192`, `512x512`, `favicon.svg`)

## 2. Как бесплатно выложить на Cloudflare Pages за 1 минуту
1. Зайдите в панель [Cloudflare Dashboard](https://dash.cloudflare.com/) → раздел **Workers & Pages** → нажмите **Create**.
2. Перейдите на вкладку **Pages** и выберите **Upload assets** (Direct Upload).
3. Введите имя проекта (например, `nutriscan-ai`) и перетащите распакованную папку проекта (или сам архив).
4. Нажмите **Deploy site** — вы сразу получите постоянную HTTPS-ссылку вида `https://nutriscan-ai.pages.dev`.

## 3. Как установить через Chrome как приложение
- **На Android (Chrome)**: откройте вашу ссылку `https://...pages.dev` → нажмите меню «три точки» в правом верхнем углу → **«Установить приложение»** (или нажмите на всплывающий баннер внизу экрана).
- **На iPhone (Safari)**: откройте ссылку → нажмите **«Поделиться»** → **«На экран „Домой“»**.
- **На ПК (Chrome / Edge / Яндекс)**: нажмите на значок установки справа в адресной строке.
